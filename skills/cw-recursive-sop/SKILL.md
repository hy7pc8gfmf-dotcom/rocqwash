# cw-recursive-sop: ConstructiveWorld 递归式演进执行 SOP

递归式演进的执行级 SOP——把递归链的建网、转环、自纠、安全推进固化为可复用的操作规程。任何项目/仓库的递归式演进改造与运行均适用。

## 触发条件

凡用户令「递归式演进」「自裁决推进」「递归链」「递归式思路」或涉及「跑完一票不停」「元验证层」「验证器的验证器」等概念时加载本技能。

## 核心理念

递归式演进＝系统在运行中改进自己的验证网、修复红案、扩展能力面，并将每轮经验回写正典——下一轮起点高于上一轮。

三个必要条件（缺一退化）：①元验证层（验证器的验证器）②递归链自裁决（免候令续环）③经验回写正典（白皮书/分诊表/exp 卡同轮）。

## 七律（递归链铁律）

1. **完成即续**：收官→回执→台账→自动取下一票禁停
2. **升格拦截**：五类（代码树写/超帽/网络×3/语义歧义/越权）→挂起候裁禁带病续工
3. **帽控**：单 run 帽（4-8 票）·清空=收队·帽满=续环
4. **收队回执**：收队卷必载逐票台账/下一轮候选/NEXT_ACTION
5. **回传**：经验入卡→回传包预铸
6. **值守**：收队后值守哨可选
7. **自续环**：收队≠停机——按 STANDING-ROLE 重铸下一轮；停机仅三类（升格/用户停止/census 零增长两轮）

## 七支柱（方法论）

1. **契约先行并行法**：接口冻结在契约面→席位互不等零交叠
2. **多飞谱系**：首飞→升级→裁决→修正→续飞→绿（红=闸抓真问题的信号）
3. **元验证层**：test_tool_selftests 枚举全工具 --selftest·红/缺/未豁免 fail-loud
4. **红必吐**：失败印首 40＋尾 20 行＋fail-first 摘要（禁裁剪吞红）
5. **双盲互证**：两独立诊断收敛＝根因实锤
6. **帽对表**：declared cap vs git diff 实际文件集（超帽=blocker）
7. **自续环**：STANDING-ROLE 常驻岗位书（收队→census→组队→重铸→循环·停机三类）

## 层律三档（并行安全不变量）

| 层 | 规则 |
|---|---|
| 数据层 | 自动·台账追加走重试循环 |
| 代码层 | gated·自裁决限机械可判项·语义歧义/越权升格·多执行者经 PR |
| 宪法层 | 永不自动 |

并行安全五规则：台账追加重试循环／B 闸 actor 去重键／plan 状态 actor 命名空间／认领制撞题停火／canonical 专属层 plan-only。

## 修复轮自愈尸检律（每次修 CI 两件事）

1. **分析自愈为何没修上**（第一手实证·marker 匹配/环境差异/沙箱伪影/措辞漂移）
2. **同轮落地**：白皮书类节＋分诊表行＋经验卡（三处缺一=违规）

典型判据族：
- 同词两病判别器（v1/v2 措辞漂移→marker 数据面让自愈分流）
- 沙箱窄 PATH→忠实壳（Git Bash 全路径＋/usr/bin 前置·赋值免引号）
- 红必吐尾 N 行＋fail-first 摘要
- 元层 timeout 一次重试（负载假阳除名）
- 帽对表复核（席位射程自扩防）
- 对齐含施工件禁裸 reset --hard（须全量 stash/复制）

## 执行流程（CreateWorkflow 模板）

```
Phase 0: 撞单闸（files.glob 回执探在）＋基线复验（head==BASE·dirt 白名单）
Phase 1: N 席并行（契约先行·帽对表）
Phase 1.5: 元层/补丁收口席（如有裁决产物）
Phase 2: 五闸全稿＋集成测试（忠实壳·沙箱窄PATH判例内置）
Phase 3: 复核（帽对表＋layer-law＋survey 对表＋五闸双面抽验）
Phase 4: 推岸（API git-data·-uall/尾斜杠/--no-filters 判例内置）＋CI 判读 FULL
Phase 5: 回执＋递归输出（下一轮队列·自续环驱动）
```

## 判据族速查（六飞实战沉淀）

| 判据 | 正形 |
|---|---|
| 沙箱窄 PATH 假红 | 忠实壳：Git Bash 全路径＋PATH=/usr/bin:$PATH（赋值免引号） |
| porcelain 目录收拢 | 必 -uall＋尾斜杠守卫 |
| gitattributes eol=lf | 跨树比对必 --no-filters |
| 红不可观测 | 失败印首 40＋尾 20 行＋fail-first 摘要 |
| 元层 timeout 假阳 | 一次重试·两连才 FAIL |
| 证据快照 vs doc face | _snapshots/ 文件=corpus 非撰述·五闸豁免登记制 |
| 对齐含施工件禁裸 reset | 须全量 stash/复制后再对齐 |
